📱 Time Wasters on Social Media – Exploratory Data Analysis
📌 Project Overview

This project focuses on analyzing time-wasting behavior on social media platforms using Exploratory Data Analysis (EDA). The goal is to understand how user demographics, device usage, content consumption, and behavioral patterns contribute to productivity loss and social media addiction.

The analysis is performed using Python and visualized to uncover meaningful insights from the dataset.

📊 Dataset Description

The dataset includes information such as:

Age & Gender

Profession & Income level

Device type (Mobile, Laptop, etc.)

Time spent on social media

Watch reasons & content preferences

Addiction level

Productivity loss

🛠️ Tools & Technologies Used

Python

Pandas – Data manipulation

NumPy – Numerical operations

Matplotlib & Seaborn – Data visualization

Jupyter Notebook

🔍 Key Analysis Performed

Data cleaning and preprocessing

Distribution analysis of time spent on social media

Productivity loss vs addiction level

Impact of age, profession, and income on usage patterns

Device-wise and content-wise usage analysis

📈 Insights & Findings

Higher addiction levels strongly correlate with productivity loss

Younger users spend more time on social media compared to older age groups

Mobile devices dominate social media consumption

Entertainment-based content leads to longer watch times
